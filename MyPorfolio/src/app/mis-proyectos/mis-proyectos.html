Proyecto final de carrera

WMotorPro

Aplicación web de gestión para un taller mecánico, desarrollada como proyecto final de la carrera de Técnico Superior en Desarrollo de Software.

El sistema permite gestionar las principales tareas del taller, desde la administración de clientes y vehículos hasta la organización de turnos, órdenes de trabajo y facturación.

Funcionalidades principales

  • Gestión de clientes y vehículos.
  • Solicitud, asignación y confirmación de turnos.
  • Administración de órdenes de trabajo y empleados.
  • Gestión de repuestos y control de existencias.
  • Facturación y registro de movimientos económicos.
  • Panel de control con información y estadísticas del taller.
  • Acceso diferenciado según el rol del usuario.

Tecnologías utilizadas

Java Spring Boot Angular MySQL Git
